# Work Hours & Time Card Calculator

A premium, animated landing page with a working work hours calculator and a 1,000+ word SEO article targeting the keyword **"time and calculator"**.

## Files

| File | Purpose |
|------|---------|
| `index.html` | Main page: design, calculator, article, animations and inline SVG images |
| `robots.txt` | Tells search engine crawlers which pages they may index |
| `sitemap.xml` | Lists the page URL for search engines |
| `README.md` | Project documentation |

## Features

- Luxury dark theme with gold accents and a shimmering headline
- Animated background glow, floating clock illustration and rotating clock hands
- Scroll-reveal animations for each section
- Working work hours calculator (handles overnight shifts and unpaid breaks)
- Semantic HTML5 structure (`header`, `main`, `article`, `section`, `figure`, `footer`)
- Single-level heading hierarchy (H1, H2, H3) for SEO
- Images are inline SVG, so they load instantly with no external requests
- Respects `prefers-reduced-motion` for accessibility
- Mobile responsive layout
